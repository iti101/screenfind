# Hand-in checklist (Quickscan)

Gebruik dit vóór je inlevert.

## Documenten (losse PDF's, geen ZIP)

- [ ] Functioneel ontwerp PDF (exporteer vanuit `docs/functioneel-ontwerp.md`)
- [ ] Titelblad met naam, datum, leerlijntitel
- [ ] Genummerde pagina's + inhoudsopgave
- [ ] ≥4 user stories, ≥4 use cases, ≥25 eisen
- [ ] ≥3 inspiratiescreenshots + toelichting
- [ ] ≥5 **papieren** wireframes (foto/scan) — print `docs/wireframes/*.svg` als hulplijn, teken op papier
- [ ] ≥5 Figma-schermen + publieke link
- [ ] Verantwoordingsdocument PDF (exporteer `docs/verantwoordingsdocument.md`)
- [ ] ≥5 technische keuzes + reflectie
- [ ] ≥5 functionele limitaties
- [ ] Publieke GitHub-URL
- [ ] APA-bronnenlijst
- [ ] AI-tool in bronnenlijst + prompts in bijlage
- [ ] Casus goedgekeurd door docent (`docs/casus.md`)

## ZIP (broncode)

- [ ] Projectmap zonder `node_modules` en zonder `.idea`
- [ ] `README.md` installatiehandleiding
- [ ] `novi/screenfind-init.json`
- [ ] `.env` met werkende TMDB + NOVI project id (keys meegeleverd)
- [ ] Geen RAR

## App

- [ ] JS + React + Context (geen TS/Redux)
- [ ] Geen Bootstrap/MUI/Tailwind
- [ ] React Router + dynamic + private routes
- [ ] ≥6 async API-functies met loading/error UI
- [ ] ≥6 herbruikbare componenten
- [ ] ≥20 commits, ≥5 gemergede PRs naar main
- [ ] `npm run dev` start zonder crash
